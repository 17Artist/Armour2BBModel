      使用说明

      1. 导入

        选择或拖入 .armour / .awsk 文件，转换在浏览器本地完成。

      2. 检查

        拖动旋转，滚轮缩放，也可使用方向键与下方按钮。选择分类后自动适配视角。展开来源记录查看原部件及挂点，切换“纹理”查看图集。

      3. 导出

        下载完整模型或当前分类。在 Blockbench 中选择“文件 → 打开模型”，导入 .bbmodel。

      预览显示静态姿态，导出的动画可在 Blockbench 中播放。模型分为头、上半身、下半身、鞋、装饰，每个方块仅属一类。完整下载包含全部分类；单类下载保留该类骨骼、纹理和动画。选中来源记录时仅预览该来源，单类下载暂时停用。
